# Michaeli & Rom | מיכאלי ורום

Bilingual responsive website preview, in Hebrew and English.

- Hebrew: `index.html`
- English: `en/index.html`
- Shared styles: `base.css`, `style.css`
- Interactions: `site.js`
- Hero video and sunlight: `hero-motion.js`, `assets/hero-landscape.mp4`

Open `index.html` directly or serve this directory with `python3 -m http.server 8765`.
No build step is required. The committed HTML, CSS, JavaScript and assets constitute the static site.

Includes 20 pages, a language switch, sticky navigation, searchable FAQs, GSAP motion, Lenis scrolling and a silent looping hero video. System reduced-motion preferences are respected.

This is a review preview. Contact forms do not send or store enquiries. Contact details, branch addresses, social links and calendar integration still need final information. WordPress/Elementor migration is a later phase; earlier packages and local content-extraction files are excluded from this repository.

Fonts, brand artwork and client content remain subject to their respective owners' licenses. Poppins license is included in `assets/fonts/Poppins-OFL.txt`.
